Add `Checkbox`, the third of the ten v0.1 fields.

`required` on it means checked, which is what the HTML attribute of the same
name means and what accepting terms needs — so the question the resolution asks
became `satisfiesRequired`, put to the field rather than decided centrally.
`false` is a value a numeric field holds and a checkbox does not.
