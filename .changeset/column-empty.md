Say something better than a dash where a row holds nothing. `.placeholder()` puts words there, which are words and not a value: not formatted, not what a sort orders by, and not what the row holds. `.default()` stands a value in instead, and it goes through everything a stored one goes through, so a default of `0` under `numeric` reads as the locale writes zero; it changes what is shown and nothing else, so a sort still orders by what the database holds. An empty state can also re-offer the table's own header actions, named rather than declared again: an action declared twice is authorised twice and the second place is the one somebody forgets, so the empty state can only offer what the header already offers this reader.
